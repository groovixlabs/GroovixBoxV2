Project mode R1

A project holds every track, pattern, preset choice and the tempo. There are 8 pages of 64 project slots.

  • Tap a slot to open that project. The open project is saved first. Tapping an empty slot starts a new, empty project there.
  • Opening Project mode shows the page that contains the open project.
  • Hold SHIFT and press B1–B8 to go to page 1–8, the same way SHIFT + B changes the track page in Note and Pattern mode. The buttons are labelled PG1–PG8 in the simulator.
  • Hold R1 and press B1–B8 does the same. This also works from any other mode: hold R1, press B3 and Project mode opens on page 3.
  • R6 + source + destination copies a project, also across pages (change page between the two taps). Copying the open project includes unsaved changes.
  • R5 + slot clears that project straight away — there is no undo on the device. Clearing the open project leaves you with an empty one.
  • The file isn't deleted, though. It is moved into trash/<date>_<time>/ inside the data folder, so a mis-tap can be put right by copying the file back into place. Two clears in the same second share a folder and never overwrite one another. See Saving.
  • A project with no steps and default settings is not saved: its slot shows as empty.

Slots are written page.slot: 3.08 is page 3, pad 8.
