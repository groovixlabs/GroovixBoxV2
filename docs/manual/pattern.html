Pattern mode R4

Choose which pattern the selected track plays. Every pad is one of its 64 patterns — nothing to page.

  • Tap a pad to make the track play that pattern. It switches immediately, keeping the playhead position. Pads read left to right and top down, so pad 1 is pattern 1 and the last pad is pattern 64.
  • One pad is green: the pattern the track plays. There is always exactly one — a track plays one of its patterns and never none.
  • The whole of a track’s choice is on screen. The grid is 64 pads and a track has 64 patterns, so nothing pages the patterns — there is no page to find, no page to remember, and no pattern you have to go looking for.
  • B1–B8 pick the track and SHIFT + B1–B8 the track page, which is what the buttons do in Note mode, Scale, Params and Global settings too. Walking the tracks is the same gesture wherever you are, and the mode stays open while you do it, so you can give one track after another a pattern without being thrown anywhere.
  • Rows 5–8 are the built-in bank — patterns 33–64 — and light amber instead of blue. Tap one and the track plays it at once; R6 copies it up to rows 1–4 to make it yours; R5 leaves it alone.
  • SHIFT takes no pad row here. Both rows the other modes claim — the top one for pages, the bottom one for mutes — are still patterns, so SHIFT never changes what a pad does. On the buttons it means the same as in every other mode: SHIFT + R4 opens Scenes, SHIFT + R3 Global settings, and so on.
  • A muted track’s whole grid dims, so it is plain why nothing is coming out of it while you try patterns against a scene. The mutes themselves are a bare press elsewhere — the mixer’s MUTE row, or the bottom pad row in Scenes — and they belong to the session, not to a mode: they stay as they are while you flip between patterns and scenes with SHIFT + R4 and R3, which is what makes auditioning a pattern inside a section work.
  • R5 + pad clears a pattern. R6 + source + destination copies one — and because a pattern remembers which track it belongs to, you can press B1–B8 between the two taps to copy a pattern to another track.

The built-in bank

Patterns 33 to 64 — the bottom half of the grid, rows 5 to 8 — hold material that ships with the instrument instead of material you made. Tap one of those amber pads and the track plays it straight away: there is nothing to load, nothing to set up, and no page to go to first.

What a track’s bank holds follows its place in its page of eight, so the roles repeat all the way up to track 64.

  • The drum and fill patterns use the General MIDI drum map, and the pitched ones are in C minor, so a drum, a bass and a chord pattern picked at random sit together.
  • Eight of each role’s 32 slots are filled. The rest are empty, left for the set to grow into without moving what is already there.
  • The bank is read-only. R5 will not empty it, the step pads will not edit it, and its patterns keep the length they ship with. To make one yours, hold R6, tap the amber pad, then tap a pad in rows 1–4 — the ordinary pattern copy. Copying into the bank is refused.
  • To stop a track playing one, give it something else to play. Because the bank is read-only, R5 cannot empty a factory pattern the way it empties one of yours, and a track always plays exactly one of its patterns — so there is no way to un-pick one. Tap any grey pad in rows 1–4 instead: an empty pattern of your own, which keeps the track running in step with everything else and plays nothing. That choice is saved with the project. For a quick silence mid-take, mute the track from the mixer’s MUTE row or Scenes’ bottom pad row, which dims its whole grid here; mutes belong to the session, not the project. Both work on any track, including one several track pages away that you landed on by mistake.
  • It costs nothing. The bank is not part of a project, so no project file carries it: an empty project is still 32 bytes with the whole bank available, and clearing a project leaves the bank alone. A track page’s button lights blue for your work only, so the bank does not make every page look busy.
