Pattern mode R2

Choose which pattern each track plays. Columns are tracks, rows are patterns, top row first.

  • Tap a pad to make that track play that pattern. It switches immediately, keeping the playhead position.
  • Each column has one green pad: the pattern that track plays. A track whose pattern is on another pattern page shows no green.
  • The bottom row pages the grid, with or without SHIFT: B1–B4 show tracks 1–8, 9–16, 17–24 or 25–32 — the columns — and B5–B8 show patterns 1–8, 9–16, 17–24 or 25–32 — the rows. Four of each, so the row divides in half. The pattern page applies to every column. Each button is green for the page on screen, blue for a page holding something, grey for an empty one.
  • The mixer’s A2 row (REC ARM on a MIDI Mix) mirrors it, split the same way: A2 1–4 the track pages, A2 5–8 the pattern pages, lit for the pages on screen. Either row moves both.
  • Because the pages are there, SHIFT here means one thing only — the bottom pad row is the mutes — and on the buttons it means the same as in every other mode: SHIFT + R2 opens Scenes, SHIFT + R1 Global settings, and so on. The bottom buttons ignore it, so you can change page with a hand still on the mutes.
  • Tapping a pad also selects its track, which is how you pick one here now that the buttons are pages: touch the column, then R3 to open Note mode on it.
  • SHIFT + a pad on the bottom row mutes that column’s track. While SHIFT is held the bottom row becomes the mutes — the track’s colour means it plays, dark means it is silent — the same way SHIFT turns the buttons into page maps. A muted track’s whole column dims, so it is plain why nothing is coming out of it while you try patterns against a scene.
  • The mutes belong to the session, not to a mode: they stay as they are while you flip between patterns and scenes with SHIFT + R2 and R2, which is what makes auditioning a pattern inside a section work.
  • R5 + pad clears a pattern. R6 + source + destination copies a pattern, also to another track or page.
