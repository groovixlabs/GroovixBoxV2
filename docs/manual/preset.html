Preset mode SHIFT + R2

Pick the voice the selected track’s gear plays. Each pad is one voice of that device’s own list, read from a CSV at startup — so a pad is CFX ConcertGrand, not a bank and a program number.

  • Select the track first with B1–B8 (which goes to Note mode), then SHIFT + R2. A tap of R2 here goes on to the step parameters, which is what the button means everywhere else.
  • Tap a pad to send that voice to the track’s gear, on its channel and port: Bank Select — MSB (CC 0) then LSB (CC 32) — and then the Program Change, which is what makes the gear act on the bank. All three come from the voice’s row in the list. The bank is a 14-bit pair and a synth keeps the half it isn’t sent, so both go out every time rather than leaving a stale LSB to decide the bank. It is sent again whenever the track’s channel, port or instrument changes, and for every track when a project opens, so your gear comes back on the right patches.
  • Opening Preset mode shows the window and page of the track’s current preset. Hold SHIFT (or R2) and press B1–B8 to change page — 64 voices each.
  • SHIFT + the bottom pad row picks the window, 512 voices each. Eight windows reach 4096 voices. While SHIFT is held the row shows them in the usual colours — green the window on screen, blue one holding voices, grey one past the end of the device’s list — so a 1,650-voice keyboard reads as four lit and four dark. The simulator labels them W1–W8.
  • The window follows the track. Nothing is stored for it: re-entering the mode opens on whichever window holds that track’s own voice, so a track on a piano and one on a drum kit each come up where their sound is.
  • A page panel gives the windows a pad row of their own — all eight, one press each, on the row directly above its preset pages. Window on one row and a page of it on the next, like a row of tabs over what the open tab shows, and both visible the whole time with nothing held.
  • A pad past the end of a device’s list is a voice it hasn’t got: dark, and deaf to a tap. So is a window past the end, on the pads or on the panel — with no voice list configured the built-in General MIDI list is 128 voices, one window’s worth, so only the first lights.
  • Every pad looks the same but the one in use, which is green: a preset is a voice in the gear, not something the sequencer keeps, so there is nothing for a pad to be full or empty of.
  • Where the list comes from. voices.conf in the config directory says which CSV belongs to which device, and the CSV is the maker’s own list pasted in whole — a PSR-SX920’s runs to 1,650 voices. Slot n is the nth voice of the file, so 1.01 is its first. A device with no list plays the built-in General MIDI one: bank 0, 128 programs.
  • The list follows the gear, not the port. Which voices a pad offers is decided by what the track’s port is wired to at that moment, so a REFRESH that moves a synth to another port takes its voices with it.
  • R5 and R6 do nothing here — there is nothing to clear or copy. In every other mode they act on something the sequencer holds; a patch lives in the synth.

The status line names the voice. PRE 1.01 104:21:0 CFX ConcertGrand — pad 1 of page 1, sending MSB 104, LSB 21, program 0. Voice lists print the program from 1, so gear showing 1 and a log showing 0 mean the same patch.

Pages sit inside windows. 8 pages of 64 make a window of 512, and SHIFT + the bottom pad row picks one of 8 windows — 4096 voices in all, which is room for any list you are likely to paste in.

A screen beside the instrument spells out where you are along the bottom: WINDOW 2 · PAGE 3 · PRESET 641. The grid cannot say it — a window and a page are each one pad among eight identical ones — and the preset is the whole voice number, which is what a device's own list counts by. It is the track's voice, so it stays put when you page away from it and the green pad goes off screen.
